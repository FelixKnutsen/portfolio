Three art directions

Working prototypes that present the same verified content in three different visual languages. They run only on the dev server and are not part of the production build.

  • A, FeatureEditorial. Newsprint, ink and oxblood, one serif, black-and-white photography, projects as magazine spreads.
  • B, InstrumentExperimental. Dark olive and amber, IBM Plex, a 3D layer model of people, process and technology that lights each project’s thread.
  • C, PlanModernist. Concrete, black and pine, Host Grotesk, an architect’s project index with plans drawn for each project.
